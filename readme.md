A **Sleek** and **modern** looking **VirusTotal Simplifier**, Quickly scan files without logins! This is my take on Virustotal.

![Preview](https://img.shields.io/badge/preview-live-success)
**Live Demo:** [virustotalsimplifier.netlify.app](https://virustotalsimplifier.netlify.app)

## ✨ Features

### 🎨 Modern UI/UX
- **Dark/Light Mode** with smooth transitions
- **Custom Color Themes** for buttons
- **Responsive Design** for all devices
- **Animated Progress Bars** with gradient effects
- **Glassmorphism Modal Dialogs**

### 🔐 Security & Performance
- **Secure API Proxy** (no exposed API keys)
- **CORS Protection** via Netlify Functions
- **File Validation** (32MB limit)
- **Real-time Polling** with exponential backoff
- **Optimized Loading** states

### 📊 Scan Capabilities
- **URL Scanning** - Analyze websites for threats
- **File Scanning** - Upload files up to 32MB
- **Detailed Reports** - Results from 70+ antivirus engines
- **Visual Statistics** - Color-coded threat indicators

## 📊 Understanding Results

| Color | Level | Meaning |
|-------|-------|---------|
| 🟢 Green | Safe | No threats detected |
| 🟡 Yellow | Suspicious | Potential threats found |
| 🔴 Red | Malicious | Confirmed threats detected |
| ⚫ Gray | Undetected | No analysis available |
